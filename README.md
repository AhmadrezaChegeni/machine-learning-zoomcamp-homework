## Overview

This repository contains my homework assignments, practical exercises, and projects completed during the **[Machine Learning Zoomcamp 2026](https://github.com/DataTalksClub/machine-learning-zoomcamp)**, created by [Alexey Grigorev](https://github.com/alexeygrigorev) and the DataTalks.Club community.
The course provides a hands-on introduction to machine learning, covering the complete workflow from problem formulation and data preparation to model training, evaluation, deployment, and scalable model serving.
